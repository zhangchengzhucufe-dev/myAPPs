# 背单词 · 安卓 APP 使用说明

手机和电脑功能完全一样（同一份界面与逻辑），数据通过家里 WiFi 双向同步。

## 一、安装 APP

1. 把项目根目录的 **`背单词.apk`** 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 手机上点开安装，首次会提示"允许安装未知来源应用"，允许即可。
3. 打开 APP。首次启动会自动载入内置词库，之后与电脑同步会把两边的词合并到一起。

## 二、设置同步（只需一次）

前提：电脑和手机连**同一个 WiFi**（家里路由器即可）。

1. 电脑双击 **`背单词.bat`**，弹出的窗口里会显示两行地址，找到「手机(同一WiFi)」那一行，比如：
   `http://192.168.1.5:8642/`
2. 手机 APP → 底部「更多」→「数据同步」→ 在"电脑地址"里填 `192.168.1.5:8642`（不带 http://）→ **保存**。
3. 完成。之后：
   - APP **每次打开自动同步**，也可随时点「🔄 立即与电脑同步」手动同步；
   - 电脑端页面开着时，手机同步的进度约 **20 秒内自动出现**，无需刷新；
   - 电脑上背的词，APP 打开就能看到。

> 提示：首次同步若 Windows 弹出防火墙提示，勾选「允许访问」。电脑的 IP 如果哪天变了（换网络），在 APP 里改一下地址即可；家用路由器也可以在后台把电脑 IP 固定。

## 三、同步会怎么合并（不会互相覆盖）

同步是**双向叠加合并**，两边的数据都保留：

| 情况 | 合并结果 |
|---|---|
| 一边新增的单词 | 两边都出现 |
| 同一个词两边都背过 | 学习日期取更早的那次（真实首次学习时间） |
| 一边改过中文释义 | 取改得更晚的释义 |
| 重点标记 | 任一边标了就算重点 |
| 复习进度（T+0/1/3/6） | 取并集，进度不倒退 |
| 一边删除了单词 | 另一边同步后也删除；删除后又重新添加的词不会被误删 |
| 每日学习记录 | 取较大值 |
| 背诵/复习用时排名 | 两边记录都保留 |
| 外观主题 | 各设备保持各自的选择 |

## 四、备份（建议偶尔做一次）

APP 数据存在手机本地。**更多 → 数据同步 → ⬇️ 导出备份文件** 会把完整备份存到手机「下载」目录；换手机或卸载重装前，先导出一份，在新设备上「⬆️ 导入备份文件」选**合并导入**。

## 五、常见问题

- **同步失败提示**：确认电脑上 `背单词.bat` 的窗口开着（关掉窗口 = 停止同步服务）、手机与电脑在同一 WiFi、地址填写正确（IP 变了要更新）。
- **手机流量/热点**：手机开热点、电脑连热点也可以同步（此时地址填电脑在热点网络下的 IP）。
- **APP 装好还要电脑吗**：不用。APP 完全独立可用，电脑只是同步的另一端。
- **电脑端入口不变**：双击 `背单词.bat` 或直接双击 `背单词.html` 打开，功能与之前一致。

## 六、给维护者

- 手机端不是重写的：`android/` 是一个 WebView 壳工程，打包的就是仓库里这份 `背单词.html`（Gradle 构建时自动复制为 assets/index.html，单一数据源）。
- 壳与页面的接口（`window.Beidan`）：`keepScreenOn`（背诵/复习时屏幕常亮）、`saveFile`（导出备份到下载目录）；页面另暴露 `beidanSync`（开机自动同步）、`beidanBack`（返回键接退出确认）、`beidanPause/beidanResume`（后台计时报表）。
- 构建：`JAVA_HOME=~/tools/jdk-17 ANDROID_HOME=~/tools/android-sdk ~/tools/gradle-8.7/bin/gradle -p android assembleRelease`；签名密钥 `~/tools/keystore/beidan.jks`（密码见同目录 properties）。
- 功能回归测试：`/tmp/beidan_test/test_app.py`（Playwright，模拟电脑端 + 手机端 + 同步服务器，52 项断言）。
